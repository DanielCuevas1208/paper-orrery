# Changelog

All notable changes to this project are listed in this file.

## [1.0.0] - 2026-08-02

- Added Keplerian orbit propagation from bundled elements.
- Added geocentric planet and Sun positions with light-time correction.
- Added precession from the J2000 frame to the equinox of date.
- Added conversion to altitude and azimuth for one location.
- Added an SVG all-sky chart renderer.
- Added a command line interface for positions and charts.
- Added xUnit tests with published almanac fixtures.
- Added a CI workflow for .NET 8.

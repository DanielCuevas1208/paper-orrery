# Roadmap

Paper Orrery keeps a narrow, offline astronomy scope.

## Possible next steps

- Add higher-precision ephemeris data.
- Add optional atmospheric refraction.
- Add a configurable star magnitude limit.
- Add observer elevation as an input.
- Add chart controls for labels and visible objects.

These ideas are not implemented.

## Boundaries

- No network service is required.
- No account or tracking feature is planned.
- Date support remains limited by the bundled orbital elements.
